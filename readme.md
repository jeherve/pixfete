This plugin allows you to create multiple photo albums for important events in your life.

Create an album, generate a link and a QR code, and share them with your guests.
They can then upload photos to the album on the day of the event.
They will be able to view the album on your site, and you can display those photos live on a photo wall.

## Install

You can get that plugin on your WordPress site by going to Plugins > Add New and searching for "Event Guest Photos Sharing". You can also [find the plugin in the WordPress.org plugin directory](https://wordpress.org/plugins/event-guest-photos-sharing/).

To install it from this GitHub repo, clone the repo in your plugin's directory (usually `wp-content/plugins`), and build it with `composer install`.

## Translate
